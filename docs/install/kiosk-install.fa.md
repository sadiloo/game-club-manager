# نصب کیوسک چک‌پوینت

نصاب کیوسک بدون سؤال نصب می‌شود و پس از ۱۰ ثانیه رایانه را راه‌اندازی مجدد می‌کند.

دادهٔ کیوسک در `C:\ProgramData\Checkpoint\kiosk\` نگه داشته می‌شود (`setup.json`، `device.json`).

در اولین اجرا، آدرس سرور و رمز مدیر کیوسک را وارد کنید؛ متن دقیق در راهنمای محصول (اسپک راه‌اندازی اول).
